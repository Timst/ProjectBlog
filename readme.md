This is the repository for my website, https://timothy-daniel.com/.

It's building using [VitePress](https://vitepress.dev/), a static website generator, and a modified version of the [VitePress Blog theme](https://chunge16.github.io/vitepress-blogs-theme/). The site itself is hosted on [Render](https://render.com/), and set to update every time commits get pushed here.
